# book-tracker
Веб-приложение для отслеживания прочитанных книг, статуса чтения и оценивания прочитанного

## Список референсов

## Что пользователь может длеать на веб-приложении
-Зарегестрироваться и войти в аккаунт
-Искать и добавлять книги в свой список
-Указывать оценку и статус прочтения книги
-Просматривать свой список книг
-Редактировать или удалять оценки/книги из списка

## Как веб-приложение выглядит
Цветовая гамма:
  - Светлый фон, темный текст, какие-нибудь акценты ??? цвета
Статусы книг:
  - Синий - в процессе
  - Зеленый - прочитано
  - Серый - в планах
  (Одна кнопка при нажатии которой меняется ее цвет и надпись на ней)

## Главная страница
Кнопки войти/зарегестрироваться если пользователь не авторизован, иначе кнопка добавить книгу и кнопка перекидывающая в личный список книг

## Страница добавления пользователя
Три поля ввода: логин, пароль, и повторение пароля. Кнопка "зарегестрироваться" и ниже ссылка "Уже есть аккаунт? Войти"
