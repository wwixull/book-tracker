# book-tracker
Веб-приложение для отслеживания прочитанных книг, статуса чтения и оценивания прочитанного

## Что пользователь может делать на веб-приложении
- Зарегестрироваться и войти в аккаунт
- Добавлять книги в свой список
- Указывать оценку и статус прочтения книги
- Просматривать свой список книг
- Редактировать или удалять книги из списка

## Как веб-приложение выглядит
Цветовая гамма:
  - Нежно синий фон, белые рамочки с синим текстом на них

Статусы книг:
  - В процессе
  - Прочитано
  - В планах
  - Брошено

## Главная страница
Кнопки добавления книги, ввод названия, автора и возможность прикрепить картинку к ней. Ниже сам список книг с возможностью изменить ее статус и поставить оценку.

## Страница добавления пользователя
Три поля ввода: логин, пароль, и повторение пароля. Кнопка "Зарегестрироваться" и "Войти". При успешной регистрации автоматический переброс на вкладку входа.
